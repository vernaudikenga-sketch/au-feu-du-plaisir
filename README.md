# Au Feu Du Plaisir — site web

Site vitrine du restaurant africain & club **Au Feu Du Plaisir**, Agiou Meletiou 73, 11251 Athènes.
Trilingue : grec, français, anglais. Site statique (HTML/CSS/JS), sans serveur.

## Modifier le contenu
| Quoi | Fichier |
|---|---|
| Horaires, plat du jour, agenda des soirées, liens de livraison, clé de réservation | `js/config.js` |
| Textes (3 langues) et menu | `js/i18n.js` |
| Photos et logo | `images/` (voir `images/LISEZ-MOI.txt`) |

## Aperçu en local
```
python -m http.server 5173
```
puis ouvrir http://localhost:5173
